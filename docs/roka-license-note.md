Repository license layout:

1. Keep the repository `LICENSE` file as MIT for upstream-compatible code.
2. Use the root `ROKA-CONTENT-LICENSE.md` for specifically scoped ROKA
   non-code material.
3. Use `ROKA` as a project name and brand marker for the fork's specific design
   direction, not as a restriction on inherited Hermes code.

Copyright protects original expression, not abstract ideas, systems, or methods
of operation. The content license therefore limits reuse of covered ROKA text
and diagrams; it does not create ownership of the underlying idea by itself.
